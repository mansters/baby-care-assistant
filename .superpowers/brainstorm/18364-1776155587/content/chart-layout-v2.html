交互修正要点

  • ✅ 边到边布局 - 图表撑满容器，坐标轴在图表内侧
  • ✅ 虚线网格 - 横向+纵向虚线，便于读数
  • ✅ "今天"在顶部 - 避免与 X轴标签冲突，带背景徽章
  • ✅ 悬浮窗顶部居中 - 点击后出现在数据点上方
  • ✅ 垂直线滑动交互 - 点击任意位置出现垂直线，hold后左右滑动切换数据点
  • ✅ 百分位标签在右侧 - 3%/15%/50%/85%/97%

新的交互流程

  1. 用户在图表区域内点击任意位置
  2. 出现一条垂直线，指向最近的数据点
  3. 悬浮窗显示该数据点的详情（月龄、体重、百分位）
  4. 用户可以 hold住手指左右滑动 切换到相邻数据点
  5. 点击空白区域或另一个位置，重新选择
